\begin{abstract}
Standard image classifiers collapse annotation variability into a single hard label. CIFAR-10H makes it possible to model the full distribution of human responses for each image instead. We train CIFAR-adapted convolutional networks to predict these soft human label distributions and evaluate them with distributional, uncertainty-ranking, calibration, robustness, and qualitative diagnostics. The final study compares ResNet18, WideResNet-28-2, DenseNet-BC-40-12, and VGG-13-BN, then ablates loss functions, prediction heads, and the value of CIFAR-10 pretraining before CIFAR-10H soft-label fine-tuning.
\end{abstract}

\section{Introduction}
Human annotators disagree for meaningful reasons: images can be low resolution, occluded, visually ambiguous, or close to semantic boundaries between classes. A majority-vote target discards this uncertainty. CIFAR-10H provides empirical human response distributions for the CIFAR-10 test images, making it possible to predict not only the most likely class but also the pattern and magnitude of human disagreement \cite{peterson2019cifar10h,krizhevsky2009cifar}.

We model each target as a probability vector $p_{\mathrm{hum}}(y\mid x)\in\Delta^{9}$ and train a neural network to output $q_\theta(y\mid x)$. The central question is whether standard CIFAR CNN backbones can learn human-like uncertainty rather than only hard-label accuracy. We therefore evaluate distribution fit, entropy agreement, high-disagreement retrieval, calibration, robustness to synthetic corruptions, and qualitative explanations.

\section{Data and Task}
CIFAR-10H contains one soft label distribution for each of the 10,000 CIFAR-10 test images. We use a fixed 6,000/2,000/2,000 train/validation/test split with seed 42. CIFAR-10 training images are used only for hard-label pretraining; they are not used as soft-label targets.

\section{Method}
\subsection{Architectures}
We compare CIFAR-ResNet18 \cite{he2016resnet}, WideResNet-28-2 \cite{zagoruyko2016wrn}, DenseNet-BC-40-12 \cite{huang2017densenet}, and VGG-13-BN \cite{simonyan2015vgg}. ResNet18 uses a CIFAR stem with a $3\times3$ stride-1 convolution and no ImageNet-style max-pooling. WRN-28-2 tests whether a compact wide residual model is sufficient for disagreement modeling, DenseNet tests parameter-efficient feature reuse, and VGG provides a plain convolutional baseline.

\subsection{Prediction Head and Training}
The default head is a 256-unit MLP with batch normalization, ReLU, dropout, and a learnable temperature-scaled softmax. Temperature scaling is included because modern neural networks are often miscalibrated, and a scalar temperature can improve probabilistic calibration \cite{guo2017calibration}. All models use AdamW \cite{kingma2015adam,loshchilov2019adamw}, cosine learning-rate scheduling, early stopping on validation KL, and light CIFAR-safe augmentation. The main training strategy is CIFAR-10 hard-label pretraining followed by CIFAR-10H soft-label fine-tuning.

\subsection{Losses}
The primary objective is KL divergence:
\begin{equation}
\mathcal{L}_{KL}=\frac{1}{N}\sum_i\sum_c p_i(c)\log\frac{p_i(c)}{q_i(c)}.
\end{equation}
We also compare Jensen-Shannon divergence \cite{lin1991jsd} and a composite entropy-aware objective:
\begin{equation}
\mathcal{L}_{custom}=KL(p\Vert q)+\lambda\left(H(p)-H(q)\right)^2,
\end{equation}
where $H(p)=-\sum_c p(c)\log_2 p(c)$ is Shannon entropy \cite{shannon1948}. The custom term penalizes disagreement-magnitude errors directly.

\section{Evaluation Metrics}
Distribution fit is measured with KL divergence \cite{kullback1951}, Jensen-Shannon divergence, cosine similarity, soft cross-entropy, Brier score \cite{brier1950}, and total variation distance. Entropy quality is measured with Pearson/Spearman correlation, mean absolute error, root mean squared error, and signed bias. High-disagreement retrieval is measured with Precision@100, Precision@200, and Precision@500 after ranking images by predicted entropy. Calibration is measured by comparing the predicted top-class confidence with the human probability assigned to that same predicted class. We report bootstrap 95\% confidence intervals for headline metrics.

Training directly on the 6,000 soft-label training images from random initialization performs much worse than CIFAR-10 pretraining followed by CIFAR-10H fine-tuning. This supports the interpretation that the soft-label set is too small to learn visual representations from scratch, but it is useful for adapting pretrained representations to human uncertainty.

\section{Discussion and Limitations}
This task is different from ordinary classification: a model can predict the majority class correctly while still assigning the wrong uncertainty profile. For that reason, majority top-1 accuracy is only a sanity check; KL/JSD, entropy error, entropy ranking, and calibration are the central metrics.

The study has three main limitations. First, CIFAR-10H contains only 10,000 soft-label targets, so results may vary with split seed and initialization. Second, the human distributions are empirical estimates and contain sampling noise. Third, annotator subsampling is not included because the default data available in this repository contains probability vectors rather than raw annotator-level labels.

We do not include EMD/Wasserstein distance as a required metric because CIFAR-10 classes have no canonical geometric ordering. A class-distance matrix would need independent justification; otherwise EMD would introduce arbitrary assumptions.

\section{Conclusion}
We built a reproducible CIFAR-10H pipeline for predicting full human label distributions. The results show that pretrained CNNs can model human uncertainty substantially better than soft-label-only training from scratch, and that the best model depends on whether the priority is KL, JSD, entropy ranking, or calibration. The current strongest run is ResNet18 with an MLP head, while WRN-28-2 remains an attractive compact model with competitive disagreement-specific behavior.
